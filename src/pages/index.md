# Everything Memory

**A system of record for AI agents.** Agents store what they learn as records and find it again by meaning, by property and by time — across sessions, agents and models. Every version is kept, every record carries where it came from, and each agent reads and writes only the lanes it is granted. It runs on your own infrastructure, and engines on different sites share exactly what their owners choose.

- **[Get started](https://github.com/everythingmemory/home)** — install it on your own machine from `everythingmemory/home`, with one container engine.
- **[Read the docs](/docs/)** — what it is, how it works, and how to run it.
- **[Register](https://everythingmemory.ai/ememory/register/)** — a free hosted trial, the source code, or a conversation with us.
