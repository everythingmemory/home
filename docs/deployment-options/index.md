# Deployment Options

Where eMemory can run and how its stacks connect: one stack on one machine, a stack with no internet access, stacks peered into a mesh, a local stack peered with eMemory SaaS, and a multi-site enterprise mesh. Each option links to the operator guide that sets it up.

Each option is the same Docker Compose stack; what differs is where it runs and which other stacks it is peered with. See [microservice architecture](../architecture/microservice-architecture.md) for what one stack contains, and [distributed mesh architecture](../architecture/distributed-mesh-architecture.md) for peering and exchange.
