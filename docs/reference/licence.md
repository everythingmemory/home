| Use | Permitted |
|---|---|

| Testing | Yes, free |
| Production use | Only under a commercial licence |
| A field test agreed in writing | Yes, under a free written trial licence |

## When a release becomes Apache 2.0

Each release converts to the Apache License 2.0 four years after it ships.

## The Apache 2.0 parts

The bundle tool and Folder Intake are under Apache 2.0 from the start, so you can adapt how memory gets in and out without a licence.
