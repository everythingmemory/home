# e_correct

Record and manage corrections.

## Agent Guidance

This is the description the engine gives an agent for this tool, word for word.

Record and manage corrections. A correction states the truth about an SR that is WRONG, pinned to exactly one `sr_id` (one correction, one record). For an SR that is right but has since evolved, use `e_ingest adjusts=` instead.

Actions: `create` (`content` + `sr_id`, both required), `retract` (`correction_id`), `inspect` (view one), `list` (browse). A correction names one record and does not change: to change one, retract it and create another. Requires write authority over the target SR's lane. A correction supersedes the original and surfaces on `e_read` and as `has_correction` in `e_gather`/`e_timeline`.

## Actions

| Action | Does | Requires |
|---|---|---|
| `create` | Attaches a new correction to one record | `content`, `sr_id` |
| `retract` | Withdraws a correction | `correction_id` |
| `inspect` | Returns one correction with its history, or the corrections on one record | `correction_id` or `sr_id` |
| `list` | Pages through corrections | — |

A correction names exactly one record and does not change: to change one, retract it and create another. `create` requires write access to the record's lane, and `retract` to the correction's lane. `inspect` and `list` do not.

## Returns

`create` returns the new correction.

| Field | Meaning |
|---|---|
| `correction_id` | The correction's id: `cor_` and 32 hexadecimal characters |
| `version` | `1` for a new correction |
| `status` | `active` |
| `sr_id` | The record it corrects |
| `affected_srs` | A preview of that record |
| `affected_count` | `1` |
| `comment` | The comment, if one was given |

`inspect` returns a `corrections` list. Each entry has `correction_id`, `version`, `content`, `authority`, `status`, `sr_id`, `affected_count` and `history`.

## Where a correction appears

On `e_read`, with the record it corrects. On `e_gather` and `e_timeline`, as `has_correction` on the record. How to use it: [correcting a record](../../agents-how-to/correcting-a-record.md).
